# Vibe Web OS

A browser-based operating system built with pure HTML, CSS, and JavaScript. Features a desktop environment with window management, virtual file system, and built-in apps.

🌐 **Live Demo:** [https://aleckotovichsam.github.io/vibe-web-os/](https://aleckotovichsam.github.io/vibe-web-os/)

## Features

- Desktop environment with taskbar, start menu, and icons
- Window manager (drag, resize, minimize, maximize)
- Virtual file system (stored in localStorage)
- Built-in apps: Notes, Text Editor, File Manager, Settings
- Multiple themes (Dark, Light, Classic, High Contrast)
- Custom wallpapers and offline support

## Quick Start

**Online:** Visit the [live demo](https://aleckotovichsam.github.io/vibe-web-os/)

**Local:** Open `index.html` in your browser, or serve with `python -m http.server` or `npx serve`

## Tech

Pure HTML/CSS/JavaScript - no build system, no dependencies. Uses localStorage and Service Worker for offline support.
